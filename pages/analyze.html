See how your agents are actually used.

Turn local Claude Code and Codex history into a private HTML report on your machine: where time and tokens go, and which Agentify changes are worth making. It reads metadata only by default and makes no model calls.

01 · Automatic

One command, one report

Matches sessions to the current repo, writes one self-contained agentify-session-analysis.html beside your code, and opens it in your browser. HTML is the default; no model runs.

agentify analyze
02 · Preview

See the exact sources first

--dry-run lists providers, roots, file counts, bytes, scope, and the privacy contract without parsing any session bodies.

agentify analyze --dry-run
03 · Act on it

Analysis leads into config

Each recommendation includes the exact command or .agentify.yaml setting to try, so the report points straight at Tune it.

Useful by default, deeper only by opt-in. The default run parses record envelopes and counters; prompt, response, and thinking bodies are never analyzed. Every wider read is a separate, explicit flag, and nothing leaves your machine unless you opt into CLI insights.

What the report helps you decide

It connects observed usage to concrete next actions, and labels incomplete evidence instead of inventing certainty.

Usage

Where effort goes

Sessions, active days, provider mix, models, token coverage, costs, cache behaviour, and outcome signals, with missing provider data called out.

Workflow

Repeated work

Tool patterns, repeated searches, command outcomes, edited files, and where Agentify context or structural queries could remove rediscovery.

Routing

Honest suggestions

Model-routing suggestions graded against local eval artifacts when available. A cheaper route is not called proven without pass-and-cost evidence.

Exact action

Common runs

Start with the repo in front of you; widen to global history only when you want a cross-project view.

# the global pattern across projects (names stay pseudonymized)
agentify analyze --scope global --days 30 --yes
# one harness at a time for a cleaner baseline
agentify analyze --provider codex --scope current-repo --yes
# keep the HTML but skip the browser (agents, CI, SSH)
agentify analyze --no-open --yes
# a compact text brief in the terminal instead of a page
agentify analyze --format text --yes
# machine-readable output for your own tooling
agentify analyze --format json --yes

Go deeper

Privacy levels

Each level is a deliberate step past metadata, and nothing escalates on its own.

default

Metadata only

Record envelopes and counters. Shell command text is classified in memory into pattern counts and irreversible fingerprints, then never retained, rendered, or uploaded.

local opt-in

Task categories

--content local-extractive classifies in-scope prompt text in memory with deterministic rules. Only match counts and a category label survive.

structural opt-in

Config audit

--include-config reads an allowlist of provider config files and reports structural names and counts, not secrets or prompt bodies.

paid network opt-in

CLI insights

--insights cli sends a sanitized counts-only packet through an installed provider CLI. Its cost and network calls are recorded separately.

Add detail deliberately 
# task-category signals for this repo, no prompt text stored
agentify analyze --scope current-repo --content local-extractive --yes
# allowlisted Claude Code and Codex config structure in a global report
agentify analyze --scope global --include-config --yes
# re-parse every source (the cache holds normalized metadata only)
agentify analyze --scope current-repo --no-cache --yes
# global reports pseudonymize; reveal names and paths only on request
agentify analyze --scope global --show-project-names --show-paths --yes
# analyze fixtures or moved data (--source-root is repeatable, per provider)
agentify analyze --source-root claude=./fixtures/claude --source-root codex=./fixtures/codex --yes
CLI insights (paid, network)

Insights send only a sanitized, counts-only packet through the selected local CLI, with an explicit budget and timeout. Preview the exact packet and provider invocation first; --insights-dry-run produces JSON and starts no model.

# inspect the sanitized packet before anything is sent
agentify analyze --scope current-repo \
  --insights cli \
  --insights-provider both \
  --max-insights-budget-usd 0.25 \
  --insights-timeout 120 \
  --insights-dry-run \
  --yes
# a real run, pinned provider and model; keep the packet to audit the input
agentify analyze --insights cli \
  --insights-provider claude --insights-model haiku \
  --max-insights-budget-usd 0.25 --insights-timeout 120 \
  --keep-insights-packet --yes
All analyze flags 
agentify analyze \

  [--show-project-names] [--show-paths] \
  [--insights deterministic|cli] \
