The honest headline

Memory versus no memory is a large, repeatable win. Agentify versus a CLAUDE.md you maintain by hand is a tie on results; Agentify's edge is that it builds, trims and shares that memory for you.

Paired, not averaged

Each task runs with and without Agentify; we count wins and losses on the same task.

Rules set first

The verdict rule is written down before any trial runs.
