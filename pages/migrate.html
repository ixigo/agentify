Switch tools without losing threads.

Copy saved Codex sessions from a project folder, and every folder inside it, into Claude Desktop's Code tab. Or go the other way. It reads local history and makes no model calls.

Guides Switch tools Board to PR Tune it See your usage Skills
01 · Preview

Dry-run first

Lists the sessions that would move, without writing anything or opening the app. Quote the path if it has spaces.

agentify migrate "/path/to/project" --dry-run
02 · Copy

Copy and open in Claude Desktop

Uses the same selection as the preview. On macOS, --open opens each thread; look for titles starting with [codex] in Claude → Code.

agentify migrate "/path/to/project" --open
03 · Continue

Pick up where you left off

Open the imported thread and send your next prompt. Without --open, choose the project under Code → Local, type /resume and pick the title. Already inside the project? agentify migrate . --open works too.

You don't need the old tool. Migration reads saved files, so a missing Codex CLI or an expired subscription is fine. Credentials and subscriptions are never transferred, and your original sessions stay as they were.

Before you start

Needed

Node.js 20+ and Git

For the Agentify installer. You don't need agentify install in the project to migrate.

Needed

Claude Desktop

Signed in with Claude Code access (Pro, Max, Team or Enterprise). Open the Code tab and choose Local.

Needed

Saved Codex sessions

Usually in ~/.codex/sessions. Cloud-only conversations must be saved locally first.

macOS only

For --open

Uses /Applications/Claude.app. Elsewhere, skip --open and use /resume.

Choose how much to bring

Selection is by each session's saved working directory, and it includes subfolders: ~/projects/my-app covers my-app/packages/mobile but not my-app-other.

# copy without opening Desktop
agentify migrate /path/to/project
# include global instructions and memory in the archive
agentify migrate /path/to/project --include-global
# one session only
agentify migrate /path/to/project --session SESSION_ID --open
# the other direction: Claude Code → Codex
agentify migrate /path/to/project --from claude --to codex
# ChatGPT export → Claude's Code tab
agentify migrate --from chatgpt --input ./conversations.json --to claude-desktop
# every project on this machine, preview only
agentify migrate --all --dry-run
What gets copied

Conversation text, titles and past tool activity become resumable threads. An archive under ~/.claude/agentify/migration/ keeps the original records, readable transcripts, a HANDOFF.md, and the project's saved instructions and Agentify context. The command prints its exact location.

What stays behind

Credentials, provider settings, attachments outside the logs, running tools and unsaved editor state. Tool calls come across as history, not as actions to rerun.

Running it again

It's a snapshot, not a sync. Re-running skips threads you already imported and keeps anything you continued in Claude. Newer Codex messages are not merged, so finish the source session before the first import.

If something's off

“Unknown command: migrate”

Update with the installer, open a new terminal, and check which agentify for an older copy on your PATH.

No sessions match my folder

Check the folder the session was started in, or select a parent folder. If your Codex data lives elsewhere, pass --codex-home /path/to/codex-data.

The app opened but I can't find the thread

Use /resume in the Code tab and search for the printed title. Importing and opening are separate steps; the copied thread stays saved even if opening fails.

The original project folder is gone

The conversation still copies. Restore the folder, or pick an existing project folder in Claude before continuing code work.
