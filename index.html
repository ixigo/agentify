Fit

Who it's for

A good fit

  • Claude Code or Codex on a subscription (Claude Pro, Max, Team, Enterprise; ChatGPT plans for Codex)
  • You return to the same repo across many sessions
  • You use git worktrees or switch between Claude and Codex
  • Your team keeps relearning the same gotchas

Not built for

  • Pay-per-token API keys: routing and reviews start extra runs
  • One-off scripts you won't touch again
  • Teams already happy with a curated CLAUDE.md who don't need the guard, risk or routing tools
